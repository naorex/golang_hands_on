## メモ

- メインプログラムは `main()` 関数で始まる必要あり、名前空間として `package main` を必ず記述する必要あり
- 命名規則
  - 公開されるものは大文字から始める **PascalCase**
  - 非公開のものは小文字から始める **camelCase**
  - 変数名は、頭文字小文字1文字でも OK な文化（むしろ推奨）
- `GOPATH` は、Go が参照する環境変数。Go ではインストールされた場所を `GOPATH` というシステム環境変数に記憶させており、ソースコードは `GOPATH` 環境変数のディレクトリ内にある src フォルダに配置されている。したがい、
  - メインプログラムとして実行するものは、どこに置いても実行可能
  - 他のプログラムからインポートして利用するパッケージのプログラムは、`GOPATH` の src フォルダ内にパッケージ名のフォルダを用意し、そこに配置する必要あり
  - `GOPATH` に保存したパッケージ内のソースコードで用いるメソッドは、PascalCase で命名する必要あり（公開されるメソッドのため）

## 型の種類

### 整数

- int：基本的にはこれを使用。OS環境依存
- int8, int16, int32, int64：割り当てられるビット数の違い（int8 -> 8 bit, -128~127）

### 符号なし整数（負の値を持たない）

- uint：基本的にはこれを使用。OS環境依存
- uint8, uint16, uint32, uint64：割り当てられるビット数の違い

その他

- uintptr：ポイントを扱うための符号なし整数型
- byte：uint8 の別名
- rune：int32 の別名。Unicode のコードポイントを表す事を想定

### 実数（浮動小数）

- float32, float64

### 複素数

- complex64, complex128：実数部と虚数部を float32 か float64 で設定するかの違い

### 真偽値

- bool：true と false

### 文字列

- string：長さの制限無し。1文字だけ扱う場合は rune を利用可

### 値のリテラル

- 整数はそのまま数値を記載するのみ
- 明示的に8進数とする場合は `0123` のようにゼロをつける
- 明示的に16進数とする場合は `0x123` のように `0x` をつける
- 浮動小数は小数点を付けるのみ。基本的に float64 の扱い
- 浮動小数は `e` を用いて実数と指数で記述も可 `1.234e5` = 1.234\*10^5
- 文字/文字列は rune か string。シングルクォートかダブルクォート

### 型変換

- Go言語では、型変換は明示的に記述する必要あり（暗黙の型変換は不可）

## 変数のスコープ

- 作成した変数は、宣言された構文内（`{}`の設定範囲内）

## ポインタ

- ポインタ型
  - 変数宣言の際に、型の前に `*` を付けると値が保管されるメモリ内のアドレスを補間する変数として宣言される
- アドレス演算子
  - 変数のポインタを取り出す際に、変数の前に `&` を付けて値のアドレスを取り出す
- 使い方の例
  - `var 変数 *型 = &値`
- Go言語には、C言語のようなポインタを加算減算する事でアドレスを移動させたりできるが、Go言語ではあえて不可となっている。アドレスの代入は可能
